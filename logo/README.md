# Logo

| File | Use |
| --- | --- |
| `mark.svg` / `mark-512.png` | Square mark on dark tile. Org avatar, favicons, app icons. |
| `mark-transparent.svg` | Mark without tile, for placing on any dark background. |
| `wordmark-dark.svg` / `.png` | Mark + name, light text, for dark backgrounds. |
| `wordmark-light.svg` / `.png` | Mark + name, dark text, for light backgrounds. |

Colors: background `#14121f`, gradient `#ff7a59` → `#a855f7`, text `#f4f1ff` / `#14121f`. Wordmark type is JetBrains Mono Bold, converted to paths.
